Formulaire de contact — Risque : Modéré

Chatbot IA — Risque : Élevé
RisqueSource de menaceVraisemblance (1–4)Gravité (1–4)NiveauMesures existantes
Transmission de données sensibles à Cohere (USA) Utilisateur saisissant des données personnelles dans le chat (nom, numéro, données de santé) 33 Élevé Pas d'avertissement visible. Pas de filtre côté serveur avant envoi à Cohere.

Comptes utilisateurs — Risque : Modéré
RisqueSource de menaceVraisemblance (1–4)Gravité (1–4)NiveauMesures existantes
